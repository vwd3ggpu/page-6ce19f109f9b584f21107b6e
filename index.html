使用场景

远程办公与学习

在差旅或家庭网络中访问公司资料、课程平台和公开文档时，用规则模式把指定域名交给加速线路，其余流量直连，减少不必要的额度消耗。

流媒体观看

旗舰版写明包含全节点原生流媒体解锁。不同平台对地区和地址的要求不同，导入订阅后应单独测试目标应用，而不是默认所有节点都能播放。

游戏延迟优化

旗舰版包含 IPLC 专线的游戏加速说明。游戏更看重稳定与丢包，建议固定少数低延迟节点，并避免与大流量下载同时占满带宽。

家庭或多设备

基础版支持 3 台、旗舰版 5 台、团队版 20 台同时在线。手机、电脑和平板应分别计数，超出套餐上限时后连入的设备可能无法使用同一订阅。

客户端选择

客户端是本页的重点。clashmi官网不把安装包放在外链上，请在确认系统后再从你信任的获取渠道下载，并只导入自己的订阅。下列是按平台做选择时的常见对照，名称可能随版本更新而变化。

Windows

优先选择支持 Clash 订阅、系统代理和可选虚拟网卡的桌面客户端。办公软件较多时，用规则模式比全局模式更不容易影响本地打印机和内网地址。

macOS

选择能在菜单栏切换节点、并允许按应用或域名分流的客户端。更新系统后若代理失效，先检查是否需要重新授予网络扩展权限。

Android

使用支持订阅链接与分应用代理的客户端。省电策略可能在后台停掉代理进程，长时间下载或通话前可把客户端加入电池优化白名单。

iOS 与其他环境

iOS 需使用系统允许的 VPN 或代理类客户端，并注意描述文件或权限提示。路由器和 OpenWrt 属于进阶用法，只有在你熟悉局域网地址规划时再考虑，避免把全部设备意外送入代理。

操作说明

  1. 在下方套餐中确认月付价格、年付价格、流量和同时在线设备数。
  2. 按自己的系统在客户端区选定软件类型，完成安装并允许其创建本地代理或虚拟网卡。
  3. 在客户端的订阅或配置页面粘贴订阅地址，设置手动更新或合理的自动更新间隔。
  4. 更新成功后先选一个延迟较低的节点，用规则模式打开代理，访问一个平时较慢的网站做对照。
  5. 流媒体或游戏再单独换到对应线路测试。不需要加速的内网、银行和本地服务应保持直连。
  6. 在客户端查看已用流量。接近套餐额度或到期日前，决定续费、升级或停止更新订阅。

若订阅无法更新，先检查地址是否完整、客户端时间是否正确，以及当前网络是否拦截了更新请求。更换节点不能解决订阅本身拉取失败的问题。

常见问题

clashmi官网的客户端应该怎么选？

先按操作系统选择，再看是否支持 Clash 订阅、规则分流和你需要的系统代理或虚拟网卡。Windows 与 macOS 适合桌面长时使用，手机端要注意后台保活。不要同时打开多个代理客户端，以免端口互相占用。

机场订阅导入后没有节点怎么办？

确认订阅地址完整、没有多余空格，并在客户端里手动更新一次。若提示解析失败，检查该客户端是否支持当前订阅格式。更新成功但列表为空时，再查看账号是否过期或流量是否用尽。

基础版、旗舰版和团队版怎么区分？

基础版每月 100GB、3 台设备，面向轻量访问和基础流媒体。旗舰版每月 300GB、5 台设备，并包含全节点流媒体解锁、IPLC 游戏线路和优先工单。团队版每月 1000GB、20 台设备，适合需要更高带宽、定制路由和专人沟通的小组。

网络加速会不会让所有网站都变快？

不会。加速线路主要改善原本绕行较慢的访问，本地网站、内网和已经很快的服务往往直连更好。规则模式可以把需要加速的域名单独送出，避免全局代理拖慢国内或局域网访问。

流媒体或游戏节点不稳定时如何处理？

先在同一地区换两三个节点对比，而不是频繁切换模式。流媒体失败时检查是否选到套餐允许的解锁线路；游戏卡顿时优先看丢包和抖动，并暂停其他大流量任务。旗舰版的 IPLC 说明针对游戏优化，基础版节点池不包含这一项。

官网下载和订阅地址需要注意什么？

只从你确认的来源获取客户端，安装前核对系统版本与权限提示。订阅地址相当于账号入口，不要发到公开聊天或截图外传。本页链接都是页内锚点，不提供外部下载地址，也不收集账号信息。

到期或流量用完后会怎样？

到期或额度用尽后，客户端可能仍保留旧列表，但连接会失败或被拒绝。可在套餐说明范围内续费、升级，或停止使用并关闭系统代理，避免软件继续尝试连接失效节点。
